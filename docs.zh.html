服务接口文档

单一配置文件（services.toml）→ 多种接口格式 · 本页为中文版，英文版见 docs.en.html

简介

本服务托管于 GitHub Pages（纯静态）。后台数据只有一个文件—— services.toml，编辑它即可更新全部数据； 所有“接口”都是由它生成的静态文件，可直接用浏览器、curl、fetch、requests 调用。

每个服务变量（如 HOME、FORUM、GIT、STATUS）只对应一个域名； 值为空表示该服务未配置，不会出现在接口与页面中。

services.toml → scripts/generate-api.mjs → api/services.* + api/home.txt + go.html

数据流向：改一个文件 → 生成器产出所有接口文件 → GitHub Action 自动提交（或本地手动运行脚本）。 跳转接口 go.html 额外支持运行时实时读取 services.toml，因此即使生成文件未刷新，跳转也始终用最新配置。

配置 services.toml

在 services.toml 中定义服务变量： 

[services]
HOME = "sparkorg.dpdns.org"
FORUM = "forum.sparkorg.dpdns.org"
GIT = "git.sparkorg.dpdns.org"
STATUS = "status.sparkorg.dpdns.org"
CLOUD_ST = ""

值为空字符串表示未配置（例如上面的 CLOUD_ST），生成器会跳过它。 新增服务只需加一行，例如 BLOG = "blog.example.com"。

还可以为每个服务配置显示名称与说明（可选，未配置时自动使用变量名）： 

[labels.HOME]
zh = "主页"
en = "Home"
desc_zh = "SparkOrg 主站入口"
desc_en = "SparkOrg main site"

接口列表

Base URL：https://spark-org-im.github.io

路径类型说明
/api/services.txt text/plain 全部服务，纯文本，每行 KEY=域名
/api/services.json application/json JSON 格式（含双语 labels 与 disabled）
/api/services.yaml
/api/services.yml		 text/yaml YAML 格式（两个路径等价）
/api/services.toml application/toml TOML 格式
/api/services.ini text/plain INI 格式
/api/services.xml application/xml XML 格式
/api/services.csv text/csv CSV 格式，列：service,domain
/api/services.env text/plain dotenv 环境变量格式
/api/home.txt text/plain 主页域名（HOME），纯文本，无任何格式
/services.toml text/plain 完整配置文件（服务变量 + 可选的 labels）
/go.html redirect 跳转服务；默认 HOME，支持 ?to=FORUM 等
说明：本站为静态托管，Content-Type 由 GitHub Pages 按扩展名给出； 个别扩展名（如 .toml/.ini/.env）可能被标为通用类型，响应体格式不受影响。 静态站无法返回真正的 HTTP 302，go.html 用 meta refresh + JS 实现等效跳转。
/api/domain.txt 作为 /api/home.txt 的兼容别名保留。

数据格式

接口字段名为英文；services 是“变量名 → 域名”的映射， home 是主页变量名，home_domain 是对应的域名， labels 提供中英双语的显示名称与说明，disabled 列出配置为空的服务。 

{
  "home": "HOME",
  "home_domain": "sparkorg.dpdns.org",
  "services": {
    "HOME": "sparkorg.dpdns.org",
    "FORUM": "forum.sparkorg.dpdns.org",
    "GIT": "git.sparkorg.dpdns.org",
    "STATUS": "status.sparkorg.dpdns.org"
  },
  "labels": {
    "HOME": {
      "zh": "主页",
      "en": "Home",
      "desc_zh": "SparkOrg 主站入口",
      "desc_en": "SparkOrg main site"
    }
  },
  "disabled": ["CLOUD_ST"]
}

文档本身也分语言：根目录 docs.html 会根据浏览器语言或站点语言偏好（localStorage lang）， 自动跳转到本页（中文）或 docs.en.html（英文）。

使用示例

Shell / curl

# 全部服务，纯文本（每行 KEY=域名）
curl -s https://spark-org-im.github.io/api/services.txt
# => HOME=sparkorg.dpdns.org
#    FORUM=forum.sparkorg.dpdns.org
#    ...

# 主页域名，纯文本
curl -s https://spark-org-im.github.io/api/home.txt
# => sparkorg.dpdns.org

# JSON（含双语 labels）
curl -s https://spark-org-im.github.io/api/services.json

# YAML / TOML / XML / CSV / ENV
curl -s https://spark-org-im.github.io/api/services.yaml
curl -s https://spark-org-im.github.io/api/services.toml
curl -s https://spark-org-im.github.io/api/services.xml
curl -s https://spark-org-im.github.io/api/services.csv
curl -s https://spark-org-im.github.io/api/services.env

# 完整配置文件
curl -s https://spark-org-im.github.io/services.toml

JavaScript / fetch

// 全部服务
const data = await (await fetch('https://spark-org-im.github.io/api/services.json')).json();
console.log(data.home_domain);              // sparkorg.dpdns.org
console.log(data.services.FORUM);           // forum.sparkorg.dpdns.org
console.log(data.services.STATUS);          // status.sparkorg.dpdns.org
console.log(data.labels.FORUM.zh);          // 论坛
console.log(data.disabled);                 // ["CLOUD_ST"]

// 只要主页域名
const home = await (await fetch('https://spark-org-im.github.io/api/home.txt')).text();
console.log(home.trim());                   // sparkorg.dpdns.org

Python / requests

import requests

data = requests.get("https://spark-org-im.github.io/api/services.json").json()
print(data["home_domain"])                  # sparkorg.dpdns.org
print(data["services"]["GIT"])              # git.sparkorg.dpdns.org
print(data["labels"]["GIT"]["zh"])          # Git 服务

跳转接口

浏览器打开 https://spark-org-im.github.io/go.html 即可直接跳转到 HOME。 页面优先实时读取 services.toml 动态决定跳转目标；若读取失败或 JS 不可用，回退到生成时烘焙的 HOME（meta refresh 兜底）。

地址目标
/go.htmlHOME（默认）
/go.html?to=FORUMFORUM
/go.html?to=GITGIT
/go.html?to=STATUSSTATUS
/go.html?to=2第 N 个已配置服务（按配置顺序）
/go.html?to=other第一个非 HOME 服务（兼容旧参数）
提示：如果指定的服务未配置，会回退到 HOME；?to= 参数与实时读取均依赖 JavaScript。

配置与同步

只改一个文件：编辑 services.toml， 在 [services] 中增删变量即可；值留空表示不启用该服务。

方式说明
GitHub Action（自动） 推送 services.toml 变更后，.github/workflows/api-sync.yml 自动运行生成器并提交所有接口文件。
本地手动 node scripts/generate-api.mjs 然后提交。
跳转接口 go.html 运行时读取 services.toml，无需生成也始终最新。
