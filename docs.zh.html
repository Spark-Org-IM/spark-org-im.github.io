接口文档

单一配置文件（domain.txt）→ 多种接口格式 · 本页为中文版，英文版见 docs.en.html

简介

本服务托管于 GitHub Pages（纯静态）。后台数据只有一个文件—— domain.txt，编辑它即可更新全部数据； 所有“接口”都是由它生成的静态文件，可直接用浏览器、curl、fetch、requests 调用。

domain.txt → scripts/generate-api.mjs → api/*.txt json yaml … + go.html

数据流向：改一个文件 → 生成器产出所有接口文件 → GitHub Action 自动提交（或本地手动运行脚本）。 跳转接口 go.html 额外支持运行时实时读取 domain.txt，因此即使生成文件未刷新，跳转也始终用最新配置。

接口列表

Base URL：https://spark-org-im.github.io

路径类型说明
/api/domain.txt text/plain 主域名，纯文本，无任何格式
/api/domain.json application/json JSON 格式（含双语 labels 字段）
/api/domain.yaml
/api/domain.yml		 text/yaml YAML 格式（两个路径等价，含双语 labels）
/api/domain.toml application/toml TOML 格式（含双语 labels）
/api/domain.ini text/plain INI 格式（多值逗号分隔，含双语 labels）
/api/domain.xml application/xml XML 格式（含双语 labels）
/api/domain.csv text/csv CSV 格式，列：role,domain（纯数据，不含 labels）
/api/domain.env text/plain dotenv 环境变量格式（含 LABEL_*_ZH / *_EN）
/domain.txt text/plain 完整配置文件（primary + other 全部）
/go.html redirect 直接跳转主域名；支持 ?to=other、?to=N
说明：本站为静态托管，Content-Type 由 GitHub Pages 按扩展名给出； 个别扩展名（如 .toml/.ini/.env）可能被标为通用类型，响应体格式不受影响。 静态站无法返回真正的 HTTP 302，go.html 用 meta refresh + JS 实现等效跳转。

多语言字段

接口数据字段名为英文（primary / others / primary_domain）； 结构化格式（JSON / YAML / TOML / INI / XML / ENV）的响应中附带中英双语的 labels 字段， 前端可直接取用本地化文案。CSV 为纯数据格式，不含 labels。 

{
  "primary": ["sparkorg.dpdns.org"],
  "others": [],
  "primary_domain": "sparkorg.dpdns.org",
  "labels": {
    "primary": { "zh": "主域名", "en": "Primary domains" },
    "others": { "zh": "备用域名", "en": "Backup domains" },
    "primary_domain": { "zh": "主域名（第一个 primary）", "en": "Primary domain (first primary)" }
  }
}

文档本身也分语言：根目录 docs.html 会根据浏览器语言或站点语言偏好（localStorage lang）， 自动跳转到本页（中文）或 docs.en.html（英文）。

使用示例

Shell / curl

# 主域名，纯文本（无格式）
curl -s https://spark-org-im.github.io/api/domain.txt
# => sparkorg.dpdns.org

# JSON（含双语 labels）
curl -s https://spark-org-im.github.io/api/domain.json

# YAML / TOML / XML / CSV / ENV
curl -s https://spark-org-im.github.io/api/domain.yaml
curl -s https://spark-org-im.github.io/api/domain.toml
curl -s https://spark-org-im.github.io/api/domain.xml
curl -s https://spark-org-im.github.io/api/domain.csv
curl -s https://spark-org-im.github.io/api/domain.env

# 完整配置文件
curl -s https://spark-org-im.github.io/domain.txt

JavaScript / fetch

// 纯文本主域名
const domain = await (await fetch('https://spark-org-im.github.io/api/domain.txt')).text();
console.log(domain.trim()); // sparkorg.dpdns.org

// JSON + 双语文案
const data = await (await fetch('https://spark-org-im.github.io/api/domain.json')).json();
console.log(data.primary_domain);           // sparkorg.dpdns.org
console.log(data.labels.primary.zh);        // 主域名
console.log(data.labels.primary.en);        // Primary domains

Python / requests

import requests

# 纯文本
domain = requests.get("https://spark-org-im.github.io/api/domain.txt").text.strip()
print(domain)  # sparkorg.dpdns.org

# JSON + 双语文案
data = requests.get("https://spark-org-im.github.io/api/domain.json").json()
print(data["primary_domain"], data["labels"]["primary"]["zh"])

跳转接口

浏览器打开 https://spark-org-im.github.io/go.html 即可直接跳转到主域名。 页面优先实时读取 domain.txt 动态决定跳转目标；若读取失败或 JS 不可用，回退到生成时烘焙的主域名（meta refresh 兜底）。

地址目标
/go.html主域名（默认）
/go.html?to=other第一个备用域名（无备用则回退主域名）
/go.html?to=2第 N 个域名（primary 优先，其次 other）
提示：?to= 参数与实时读取均依赖 JavaScript；禁用 JS 时只会跳转到生成时的主域名。

配置与同步

只改一个文件：编辑 domain.txt， primary= 为多行主域名，other= 为多行备用域名，# 开头为注释。

方式说明
GitHub Action（自动） 推送 domain.txt 变更后，.github/workflows/api-sync.yml 自动运行生成器并提交所有接口文件。
本地手动 node scripts/generate-api.mjs 然后提交。
跳转接口 go.html 运行时读取 domain.txt，无需生成也始终最新。
