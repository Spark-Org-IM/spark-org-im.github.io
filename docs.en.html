Service API Documentation

Single config file (services.toml) → multiple API formats · English docs; see docs.zh.html for Chinese

Introduction

This service is hosted on GitHub Pages (fully static). The backend data is a single file — services.toml. Edit it and every endpoint updates. All “APIs” are generated static files that can be consumed with a browser, curl, fetch, or requests.

Each service variable (HOME, FORUM, GIT, STATUS, …) maps to exactly one domain. An empty value means the service is not configured and is omitted from the API and pages.

services.toml → scripts/generate-api.mjs → api/services.* + api/home.txt + go.html

Data flow: edit one file → the generator produces every endpoint → the GitHub Action commits the result (or run the script locally). The redirect page go.html also reads services.toml at runtime, so redirects stay current even before generated files are refreshed.

Configuration services.toml

Define service variables in services.toml: 

[services]
HOME = "sparkorg.dpdns.org"
FORUM = "forum.sparkorg.dpdns.org"
GIT = "git.sparkorg.dpdns.org"
STATUS = "status.sparkorg.dpdns.org"
CLOUD_ST = ""

An empty string means not configured (e.g. CLOUD_ST above); the generator skips it. To add a service, add one line, e.g. BLOG = "blog.example.com".

You can optionally provide display names and descriptions for each service (defaults to the variable name): 

[labels.HOME]
zh = "主页"
en = "Home"
desc_zh = "SparkOrg 主站入口"
desc_en = "SparkOrg main site"

Endpoints

Base URL: https://spark-org-im.github.io

PathFormatDescription
/api/services.txt text/plain All services, plain text, one KEY=domain per line
/api/services.json application/json JSON (bilingual labels + disabled)
/api/services.yaml
/api/services.yml		 text/yaml YAML (both paths are equivalent)
/api/services.toml application/toml TOML
/api/services.ini text/plain INI
/api/services.xml application/xml XML
/api/services.csv text/csv CSV with service,domain columns
/api/services.env text/plain dotenv environment format
/api/home.txt text/plain Home domain (HOME), raw plain text
/services.toml text/plain Full config file (services + optional labels)
/go.html redirect Redirect to a service; defaults to HOME, supports ?to=FORUM etc.
Note: This is a static site. Content-Type is assigned by GitHub Pages based on the extension; some extensions (.toml / .ini / .env) may be served as generic types — the response body format is unaffected. Static hosting cannot return a real HTTP 302; go.html uses meta refresh + JS for an equivalent redirect.
/api/domain.txt is kept as a compatibility alias for /api/home.txt.

Data shape

Field names are English. services maps variable names to domains; home is the home variable key and home_domain its domain; labels contains bilingual display names and descriptions; disabled lists services with empty values. 

{
  "home": "HOME",
  "home_domain": "sparkorg.dpdns.org",
  "services": {
    "HOME": "sparkorg.dpdns.org",
    "FORUM": "forum.sparkorg.dpdns.org",
    "GIT": "git.sparkorg.dpdns.org",
    "STATUS": "status.sparkorg.dpdns.org"
  },
  "labels": {
    "HOME": {
      "zh": "主页",
      "en": "Home",
      "desc_zh": "SparkOrg 主站入口",
      "desc_en": "SparkOrg main site"
    }
  },
  "disabled": ["CLOUD_ST"]
}

Docs are per-language: docs.html redirects to this page or docs.zh.html based on browser language or the site language preference (localStorage lang).

Examples

Shell / curl

# All services, plain text (one KEY=domain per line)
curl -s https://spark-org-im.github.io/api/services.txt
# => HOME=sparkorg.dpdns.org
#    FORUM=forum.sparkorg.dpdns.org
#    ...

# Raw home domain
curl -s https://spark-org-im.github.io/api/home.txt
# => sparkorg.dpdns.org

# JSON (with bilingual labels)
curl -s https://spark-org-im.github.io/api/services.json

# YAML / TOML / XML / CSV / ENV
curl -s https://spark-org-im.github.io/api/services.yaml
curl -s https://spark-org-im.github.io/api/services.toml
curl -s https://spark-org-im.github.io/api/services.xml
curl -s https://spark-org-im.github.io/api/services.csv
curl -s https://spark-org-im.github.io/api/services.env

# Full config file
curl -s https://spark-org-im.github.io/services.toml

JavaScript / fetch

// All services
const data = await (await fetch('https://spark-org-im.github.io/api/services.json')).json();
console.log(data.home_domain);              // sparkorg.dpdns.org
console.log(data.services.FORUM);           // forum.sparkorg.dpdns.org
console.log(data.services.STATUS);          // status.sparkorg.dpdns.org
console.log(data.labels.FORUM.en);          // Forum
console.log(data.disabled);                 // ["CLOUD_ST"]

// Raw home domain only
const home = await (await fetch('https://spark-org-im.github.io/api/home.txt')).text();
console.log(home.trim());                   // sparkorg.dpdns.org

Python / requests

import requests

data = requests.get("https://spark-org-im.github.io/api/services.json").json()
print(data["home_domain"])                  # sparkorg.dpdns.org
print(data["services"]["GIT"])              # git.sparkorg.dpdns.org
print(data["labels"]["GIT"]["en"])          # Git

Redirects

Open https://spark-org-im.github.io/go.html in a browser to redirect to HOME. The page reads services.toml at runtime when possible; if loading fails or JS is disabled, it falls back to the baked HOME domain via meta refresh.

URLTarget
/go.htmlHOME (default)
/go.html?to=FORUMFORUM
/go.html?to=GITGIT
/go.html?to=STATUSSTATUS
/go.html?to=2N-th configured service (config order)
/go.html?to=otherFirst non-HOME service (legacy alias)
/go.html?to=FDROID/repo/Service plus a path suffix (appended as-is)
Tip: If the requested service is not configured, it falls back to HOME. The ?to= parameter and runtime config loading require JavaScript.

Configuration & sync

Edit one file: services.toml. Add or remove variables under [services]; leave a value empty to disable a service.

MethodDescription
GitHub Action (automatic) Pushing a change to services.toml runs .github/workflows/api-sync.yml, which regenerates and commits every endpoint file.
Local manual Run node scripts/generate-api.mjs, then commit.
Redirect page go.html reads services.toml at runtime, so redirects are always current.
