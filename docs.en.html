API Documentation

One config file (domain.txt) → many API formats · English version; Chinese at docs.zh.html

Introduction

This service is hosted on GitHub Pages (fully static). The backend data is a single file — domain.txt. Edit it and every endpoint updates. All “endpoints” are static files generated from that one file — callable via browser, curl, fetch, requests.

domain.txt → scripts/generate-api.mjs → api/*.txt json yaml … + go.html

How it flows: change one file → the generator emits every endpoint file → the GitHub Action commits them automatically (or run the script locally). The redirect endpoint go.html additionally reads domain.txt at runtime, so the redirect target is always current even if generated files are stale.

Endpoints

Base URL: https://spark-org-im.github.io

PathFormatDescription
/api/domain.txt text/plain Raw primary domain, no formatting
/api/domain.json application/json JSON format (with bilingual labels field)
/api/domain.yaml
/api/domain.yml		 text/yaml YAML format (two equivalent paths, with bilingual labels)
/api/domain.toml application/toml TOML format (with bilingual labels)
/api/domain.ini text/plain INI format (comma-separated lists, with bilingual labels)
/api/domain.xml application/xml XML format (with bilingual labels)
/api/domain.csv text/csv CSV format, columns role,domain (pure data, no labels)
/api/domain.env text/plain dotenv env format (with LABEL_*_ZH / *_EN)
/domain.txt text/plain Full config file (all primary + other domains)
/go.html redirect Redirect directly to the primary domain; supports ?to=other, ?to=N
Note: this is static hosting, so Content-Type is assigned by GitHub Pages per extension; a few extensions (.toml/.ini/.env) may get a generic type — the response body format is unaffected. Static hosting also cannot issue a real HTTP 302; go.html uses meta refresh + JS as an equivalent.

Multilingual Fields

Data field names are English (primary / others / primary_domain). Structured formats (JSON / YAML / TOML / INI / XML / ENV) include a bilingual labels field so front-ends can display localized copy directly. CSV is pure data and carries no labels. 

{
  "primary": ["sparkorg.dpdns.org"],
  "others": [],
  "primary_domain": "sparkorg.dpdns.org",
  "labels": {
    "primary": { "zh": "主域名", "en": "Primary domains" },
    "others": { "zh": "备用域名", "en": "Backup domains" },
    "primary_domain": { "zh": "主域名（第一个 primary）", "en": "Primary domain (first primary)" }
  }
}

Documentation is multilingual too: the root docs.html detects the browser language or the site language preference (localStorage lang) and redirects to this page (English) or docs.zh.html (Chinese).

Examples

Shell / curl

# Raw primary domain (no formatting)
curl -s https://spark-org-im.github.io/api/domain.txt
# => sparkorg.dpdns.org

# JSON (with bilingual labels)
curl -s https://spark-org-im.github.io/api/domain.json

# YAML / TOML / XML / CSV / ENV
curl -s https://spark-org-im.github.io/api/domain.yaml
curl -s https://spark-org-im.github.io/api/domain.toml
curl -s https://spark-org-im.github.io/api/domain.xml
curl -s https://spark-org-im.github.io/api/domain.csv
curl -s https://spark-org-im.github.io/api/domain.env

# Full config file
curl -s https://spark-org-im.github.io/domain.txt

JavaScript / fetch

// Raw primary domain
const domain = await (await fetch('https://spark-org-im.github.io/api/domain.txt')).text();
console.log(domain.trim()); // sparkorg.dpdns.org

// JSON + bilingual copy
const data = await (await fetch('https://spark-org-im.github.io/api/domain.json')).json();
console.log(data.primary_domain);           // sparkorg.dpdns.org
console.log(data.labels.primary.zh);        // 主域名
console.log(data.labels.primary.en);        // Primary domains

Python / requests

import requests

# Raw text
domain = requests.get("https://spark-org-im.github.io/api/domain.txt").text.strip()
print(domain)  # sparkorg.dpdns.org

# JSON + bilingual copy
data = requests.get("https://spark-org-im.github.io/api/domain.json").json()
print(data["primary_domain"], data["labels"]["primary"]["en"])

Redirect Endpoint

Open https://spark-org-im.github.io/go.html in a browser to redirect straight to the primary domain. The page prefers a runtime read of domain.txt to pick the target; if that fails (or JS is off) it falls back to the baked-in primary domain (meta refresh fallback).

URLTarget
/go.htmlPrimary domain (default)
/go.html?to=otherFirst backup domain (falls back to primary if none)
/go.html?to=2N-th domain (primary first, then other)
Tip: the ?to= parameter and live resolution require JavaScript; without JS the page goes to the baked-in primary domain.

Config & Sync

One file to change: edit domain.txt — primary= lines are main domains, other= lines are backups, # starts a comment.

WayDescription
GitHub Action (automatic) Push a change to domain.txt; .github/workflows/api-sync.yml regenerates and commits every endpoint file.
Local (manual) Run node scripts/generate-api.mjs, then commit.
Redirect endpoint go.html reads domain.txt at runtime — always current, even without regenerating.
